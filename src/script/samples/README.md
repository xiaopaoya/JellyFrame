# Script Samples

> Last updated: 2026-07-07; Applies to: 0.5.0-dev

Samples in this directory exercise the optional JerryScript bridge.

- `classic`: classic-script probes for DOM mutation, event listeners, timers and
  script loading.

These samples can be rendered by shells that were built with
`JELLYFRAME_BUILD_SCRIPTING=ON`. They are not part of the render core.
