# 模板

> 最后更新：2026-08-25；适用版本：0.6.0-dev；兼容基线：0.5.0

JellyFrame package 的起始模板目录。

`apps/blank` 是从零开始的最小 package：`Hello world`、一个 CSS 入口和一个 classic
JavaScript 入口。

模板供工具和刚开始写 app 的开发者使用，应展示正常 package 结构，并避免依赖桌面专用能力。

完整验收示例位于 `../../samples/apps/packages`。模板是 `tools/jellyframe_cli.py new`
复制的起点；示例是用于验证 runtime、截图和回归的维护产物。
