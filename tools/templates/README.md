# Templates

> Last updated: 2026-08-09; Applies to: 0.6.0-dev; compatibility baseline: 0.5.0

Starter app templates for JellyFrame packages.

Templates are used by tools and by developers learning the supported subset.
They should demonstrate normal app structure without depending on desktop-only
features.

Complete acceptance examples live in `../../samples/apps/packages`. Templates are starting
points copied by `tools/jellyframe_cli.py new`; examples are maintained outputs
used to validate the runtime.

Audience: app authors starting a new package. Use `apps/README.md` to choose a
visual starting point; use `tests/fixtures/apps` only to reproduce a contract
or failure.
