# clock

> Last updated: 2026-11-04; Applies to: 0.6.0-dev; Render Core baseline: 0.7.0

A host-time clock based on Date.now, with UTC/UTC+8 and 12/24-hour controls. The progress bar measures the day; no health values are fabricated.

Follows [template conventions](../CONVENTIONS.md).

```powershell
.\build\desktop-scripting-release\Release\jellyframe_desktop_shell.exe --app tools/templates/apps/clock --frame-script tools/templates/apps/clock/capture_review.jfcapture
```
