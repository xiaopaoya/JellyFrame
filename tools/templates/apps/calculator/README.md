# calculator

> Last updated: 2026-09-09; Applies to: 0.6.0-dev; Render Core baseline: 0.6.2

An integer addition/subtraction starter with a four-column keypad, delegated events, eight-digit input limits and bounded results. Chained operations and repeated equals have stable behavior.

Follows [template conventions](../CONVENTIONS.md).

```powershell
.\build\desktop-scripting-release\Release\jellyframe_desktop_shell.exe --app tools/templates/apps/calculator --frame-script tools/templates/apps/calculator/capture_review.jfcapture
```
