# Blank Template

> Last updated: 2026-09-04; Applies to: 0.6.0-dev; Render Core baseline: 0.6.2

The smallest JellyFrame App package. It contains a `Hello world` page plus one
empty stylesheet and one empty classic-script entry point, each marked with a
single starter comment.
