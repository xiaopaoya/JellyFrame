# timer

> Last updated: 2026-11-04; Applies to: 0.6.0-dev; Render Core baseline: 0.7.0

A one-minute deadline-based focus timer with start, pause, reset, completion and restart. The two-segment conic ring follows the remaining time.

Follows [template conventions](../CONVENTIONS.md).

```powershell
.\build\desktop-scripting-release\Release\jellyframe_desktop_shell.exe --app tools/templates/apps/timer --frame-script tools/templates/apps/timer/capture_review.jfcapture
```
