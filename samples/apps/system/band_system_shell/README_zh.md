# 手环系统壳示例

> 最后更新：2026-07-16；适用版本：0.5.0-dev

这是一个面向 `172x320` 手环屏的图标优先系统壳视觉验收示例。表盘、启动器、快捷设置和通知均属于宿主拥有的系统界面；页面中出现的天气、运动和音乐只是系统入口，不向普通第三方 App 授予系统权限。

该样例只使用已文档化的 HTML/CSS 子集：不用 SVG、filter、运行时 HTML 解析或 JavaScript。ESP32-S3 移植目录带有等价静态资源与受限原生事件适配，用于真实开发板 bring-up；这里保留 source package 形式，供桌面检查、打包和视觉验收。

当前视觉基线使用有界 radial/conic 渐变、短文本阴影、`outline-offset`
焦点环和按压 transform 反馈；它们都只在页面声明时消费。板端壳刻意不保持常驻的路由动画循环。
